# 一、人眼视觉底层色彩理论

调色一切的基础。调色不是在调数字，是在模拟人眼感知。

## 理论一：人眼对亮度的敏感度远高于色彩

核心原理
人眼对明暗变化的感知精度是对颜色变化的数倍。人眼能分辨出极细微的亮度差异，但对颜色的分辨能力相对粗糙。这意味着：调亮度（反差）是"大手术"，调颜色是"微调"。

实操用法
- 暗部不要拉高饱和、不要乱偏色：暗部提升饱和后噪点暴增、颜色发脏
- 高光少做大幅度色相偏移：高光做色偏会导致色彩断层、视觉刺眼
- 不要强行把阴天调成大晴天：违背视觉恒常性，画面会假

---

## 理论二：视觉恒常性

核心原理
人眼会自动脑补环境色，无论现场灯光是什么颜色，我们都会把白色物体感知为白色、绿色草地感知为绿色。这是大脑的自动修正，不是缺陷。调色如果违背这个机制（强行用环境光色覆盖固有色），观众会觉得"颜色不对"。

实操用法
- 肤色永远是肤色，不会因为背景是蓝色就把脸调蓝
- 草地永远是绿的，不因为阴天就变成灰色
- 调色时先确认主体固有色，再考虑环境色影响

---

## 理论三：暗部与亮部的色彩表现差异

核心原理
- 暗部：人眼对暗部色彩不敏感，噪点在此区域最明显，高饱和容易显脏
- 亮部：人眼对亮部色彩极其敏感，色彩断层、饱和溢出在此最容易被察觉

实操用法
- 暗部保持低饱和、中性色（偏青蓝是安全的）
- 亮部允许适当饱和，但避免色彩断层
- 暗部加细节要用增益（Gain）而非降噪，防止噪点放大

# 二、HSL 色彩三维模型

选色、限定器、二级调色的核心工具。

## 核心原理

色彩由三个维度构成：
- H（Hue）色相：是什么颜色（红橙黄绿青蓝紫）
- S（Saturation）饱和度：颜色浓淡
- L（Lightness）明度：颜色亮暗

互补色固定关系：红↔青、绿↔品红、蓝↔黄

## 实操用法

### 用法1：肤色调整
- 画面脸红/红血丝：加青色（红色互补），可以减轻红感
- 想让肤色通透：减少品红色（偏洋红），微加绿色

### 用法2：HSL限定器抠颜色
达芬奇操作路径：Color页面 → Highlight抠像工具 → 选择HSL模式

在DaVinci里：
- 抠某个物体颜色：窗口（Power Window）→ HSL限定器 → 选择目标色相区间
- 只调这一区域的饱和度或明度，不影响其他颜色

### 用法3：偏色永远用互补色矫正
- 画面偏黄 → 加蓝色
- 画面偏绿 → 加品红色
- 画面偏红 → 加青色
- 偏什么色，就用它的互补色来中和

---

# 三、RGB 加色法原理

屏幕与视频调色的底层逻辑。

## 核心原理

影视、显示器均采用光的加色混合（和颜料绘画的减色混合完全不同）：

红+绿=黄
绿+蓝=青
红+蓝=品红
RGB全亮=纯白
RGB全暗=纯黑

## 实操用法

### 用法1：调RGB单通道曲线是最精准的校色方式
达芬奇操作路径：Color页面 → 曲线（Curves）→ 选择R/G/B单独通道

### 用法2：画面变暖/变冷
- 想变暖：拉高红色通道 + 绿色通道（红+绿=黄，暖色）
- 想变冷：拉高蓝色通道

### 用法3：暗部发青的处理
- 暗部发青 = 暗部红色不足
- 下拉红色通道曲线（减少红色），暗部立即恢复中性

# 四、亮度与灰阶体系

一级调色第一步必须搞懂的基准。

## 核心概念

### 黑场与白场
- 黑场（Black Level）：画面最暗处不应死黑，应有细节层次
- 白场（White Level）：画面最亮处不应死白，应保留云层等高光细节
- 18%中性灰：人眼和测光表的基准参照点，所有调色的平衡基准

### 动态范围
- 动态范围：画面能记录的最亮到最暗的跨度（单位：档/stop）
- Log素材动态范围远大于普通直出，记录了更多亮暗信息
- 直出素材动态范围小，高光暗部信息有限

## 实操用法

### 用法1：任何素材先定黑白场
达芬奇操作路径：Color页面 → Primaries（主校色）→ 拖动Lift（黑场）和Gain（白场）滑块

- 用示波器确认：波形顶部不超过1023，底部不低于0
- 黑场拉太高 → 画面发灰发雾
- 白场压太死 → 画面发闷无光感

### 用法2：画面发灰没层次
- 拉大白场（Gain向下压）和黑场（Lift向上提）
- 本质是拉开动态范围两端，增加反差
- 对应波形变化：两端向边界扩展

### 用法3：曝光不准用灰卡校准
达芬奇操作路径：Color页面 → 灰度吸管（Gray Eyedropper）→ 点击画面中的中性灰区域

- 一键修正整体曝光和色偏
- 比肉眼判断准十倍

# 五、Gamma / Gain / Offset 三大旋钮底层逻辑

达芬奇色轮的核心，务必彻底理解。

## 核心原理

| 旋钮 | 数学运算 | 影响范围 | 特点 |
|------|---------|---------|------|
| Gamma | 对数（log） | 中间调（30%~70%） | 不碰高光暗部，主调曝光 |
| Gain | 乘法（×小于1） | 高光（70%~100%） | 压高光防过曝，微牵中间调 |
| Offset | 加法（+） | 全局整体 | 亮暗+色偏一起动 |
| Lift | 乘法（×大于1） | 阴影（0%~30%） | 抬阴影去死灰，微牵中间调 |

## 实操用法

### 用法1：中间调没层次 → 调Gamma
- 画面灰蒙蒙：Gamma向右拉，抬中间灰
- 示波器变化：波形中部整体上移，两端位置几乎不变
- 这是调曝光最常用的旋钮

### 用法2：高光过曝 → 压Gain
- 天空刺眼发白：Gain向下拖（乘以小于1的系数）
- 示波器变化：波形顶部下降，高光细节显现
- 注意：压太狠画面会发闷

### 用法3：整张画面统一偏色 → Offset
- 偏黄/偏蓝/偏冷：直接动Offset整体补偿
- 示波器变化：波形整体上移或下移，同时带色彩变化
- 适合大范围色温修正

### 用法4：阴影死黑 → 抬Lift
- 暗部没细节：Lift向上提（乘以大于1的系数）
- 示波器变化：波形底部上升，暗部层次显现
- 阴天风格调色：适度抬Lift，给阴影增加厚度

# 六、色彩空间与色域理论

素材还原和最终输出的核心保障。

## 核心概念

| 色彩空间 | 应用场景 | 特点 |
|---------|---------|------|
| Rec.709 | 短视频/B站/网络视频/普通显示器 | 全网通用基准 |
| DCI-P3 | 电影院/苹果设备/广色域视频 | 比Rec.709大25%绿色和红色 |
| BT.2020 | 4K/HDR超高清 | 最广色域 |
| sRGB | 网页/普通屏幕 | 与Rec.709近似但不完全相同 |
| DaVinci Wide Gamut | DaVinci调色工作空间 | 软件内部处理用 |
| ACES | 电影工业标准 | 跨平台色彩管理框架 |

### Log格式的本质
相机Log格式（尼康D-Log M、索尼S-Log、佳能C-Log、ARRI LogC等）的核心工作原理：
- 压低高光（高光区域信息压缩）
- 拉升暗部（暗部信息展开）
- 换取超大动态范围（14~17档 vs 普通8~10档）
- 代价：画面发灰（对比度被拍平）

## 实操用法

### 用法1：Log素材第一步必须套还原LUT
达芬奇操作路径：Color页面 → LUT/3D节点 → 载入对应机型的还原LUT

- 把Log曲线还原到Rec.709
- 没有还原LUT，画面永远发灰
- LUT文件名一般含机型名（如S-Log3_to_709）

### 用法2：发抖音/B站/短视频 → 输出Rec.709
达芬奇操作路径：Deliver页面 → 输出格式选择 → 色彩空间设为Rec.709

### 用法3：院线/苹果投屏 → 转DCI-P3
达芬奇操作路径：Project Settings → Color Science → Output Color Space设为DCI-P3

### 用法4：广色域转窄色域
DaVinci自动处理，但需要在Project Settings中确认"色域映射"选项，避免颜色炸掉/饱和溢出

# 七、色温与白平衡理论

环境光色偏的矫正。

## 核心原理

### 色温（Color Temperature）
- 低K值（2700K~4000K）：暖黄/橙光
- 高K值（6000K~10000K）：冷蓝白光
- 中性（5500K~6500K）：近似日光的色温

### 白平衡的本质
找到画面中无偏色的中性灰基准点，然后抵消环境光带来的色偏。环境光色偏是叠加在固有色之上的"染色"，白平衡就是把这个叠加去掉。

### 额外：绿-品红偏移（Tint）
不是所有光源都能用色温K值描述。荧光灯、某些LED灯会产生额外的绿色或品红色偏，需要单独用色调（Tint）旋钮修正。

## 实操用法

### 用法1：室内灯光偏黄
- 拉高色温（Temperature）滑块
- 色温越高越偏蓝，越低越偏黄

### 用法2：荧光灯/霓虹灯偏绿
- 色调（Tint）往品红方向拉
- 绿色是品红的互补色，加品红即消绿

### 用法3：精准校色用灰卡
- 拍摄时放置灰卡（18%灰卡或有灰边的白卡）
- 达芬奇中用灰度吸管点击灰卡位置
- 比肉眼调准十倍，排除显示器误差

---

# 八、色彩对比与冷暖分离理论

电影感的核心美学逻辑。

## 核心原理

### 冷暖对比是调色最常用的电影配色逻辑

经典电影配色原则：
- 高光区：偏暖（黄色/橙色）→ 模拟阳光、火焰、烛光的温暖感
- 暗部区：偏冷（青色/蓝色）→ 模拟阴影、夜晚、水面的冷静感
- 这种高光暖暗部冷的分布符合人眼对自然光的认知，是"正确"的美学感受

### 互补色关系
- 暖色（黄/橙）与冷色（青/蓝）是对比最强的配色
- 同类色（黄+橙）柔和但容易平
- 互补色（黄+青）冲击强但容易脏

## 实操用法

### 用法1：电影质感的关键操作
达芬奇操作路径：Color页面 → HDR色轮

1. 打开HDR色轮
2. 暗部（Shadow/Dark）滑块往青色/蓝色方向拖
3. 高光（Highlight/Gain）滑块往黄色/橙色方向拖
4. 整体反差用Gamma调节

结果：高光暖、暗部冷，典型的电影光感

### 用法2：不要全图一个色调
- 全图都暖 → 没层次，很平
- 全图都冷 → 压抑，死气沉沉
- 正确做法：同一画面中高光和暗部有冷暖分离，主体和背景有冷暖对比

### 用法3：人像突出主体
达芬奇操作路径：Color页面 → Power Window → 抠出人物范围

- 背景偏冷（青蓝）
- 人物肤色偏暖（黄橙）
- 自动形成视觉焦点，主体从背景中脱颖而出

# 九、饱和度与亮度耦合理论

颜色"浓"不一定好看。

## 核心原理

1. 人眼感知规律：同一颜色，亮度越高感知越浓；暗部天生不适合高饱和
2. 饱和过高的问题：色彩溢出（颜色"炸"出来）、断层（色阶不连续）、噪点放大
3. 肤色特殊性：饱和过高显油腻、不真实；健康肤色饱和度有上限

## 实操用法

### 用法1：绝对禁止拉高暗部饱和
- 暗部本来人眼就不敏感，加饱和=显脏+噪点暴增
- 正确做法：想增加暗部色彩丰富度 → 先提亮暗部，再适当加饱和

### 用法2：颜色鲜艳又自然的正确方式
达芬奇操作路径：Color页面 → Primaries → 先调Exposure（提亮主体），再加Saturation

- 先用Gamma/Gain把主体亮度提起来
- 亮度提升后人眼自动感知颜色更浓
- 只需微加饱和，效果自然且不溢出

### 用法3：高光饱和溢出处理
达芬奇操作路径：Color页面 → HSL限定器 → 选择高光区域 → 降低饱和度

- 天空等高光区域降低饱和，防止刺眼
- 暗部饱和不动，保持干净

# 十、中性灰平衡理论

专业校色的核心基准。

## 核心原理

RGB三个通道数值完全相等 = 中性无偏色灰（中性灰）

任何画面偏色，本质都是RGB三条灰阶线没有对齐：
- 偏红 = R通道值 > G和B通道值
- 偏蓝 = B通道值 > R和G通道值
- 偏青 = R通道值偏低（青是红的补色）

## 实操用法

### 用法1：打开示波器分量图检查白平衡
达芬奇操作路径：监看窗口右键 → Show Scopes → RGB Parade

- 三条波形（R/G/B）完全重合 = 白平衡准确
- 红色波形偏高 = 画面偏红
- 蓝色波形偏低 = 画面偏黄（缺蓝）

### 用法2：偏色矫正
达芬奇操作路径：Color页面 → 曲线（Curves）→ 分别拖动R/G/B单通道曲线

矫正原则：
- 偏什么色 → 降低那个颜色的通道值
- R偏高 → 下压红色曲线
- B偏低 → 上抬蓝色曲线
- 直到RGB三条线在直方图上对齐

# 十一、示波器与矢量镜科学观测理论

调色是用数据决策，不是用感觉决策。

## 核心原理

| 示波器类型 | 观测内容 | 关键判断 |
|-----------|---------|---------|
| 波形示波器（Waveform） | 亮度分布（0~1023） | 高光是否过曝/暗部是否死黑 |
| 分量示波器（RGB Parade） | R/G/B三通道分离 | 白平衡偏色方向 |
| 直方图（Histogram） | 像素数量-亮度分布 | 整体亮度区间 |
| 矢量示波器（Vector Scope） | 色相+饱和度分布 | 肤色是否在基准线 |

## 实操用法

### 用法1：调人像盯矢量镜
达芬奇操作路径：监看窗口 → 打开矢量示波器（Vector Scope）

- 所有人种肤色大致沿矢量镜中的肤色基准线（Skin Tone Line）分布
- 肤色点偏离基准线 → 偏色
- 肤色点离圆心太远 → 饱和过高
- 矢量镜肤色点准确 = 肤色永远自然

### 用法2：波形示波器判断高光/暗部安全
达芬奇操作路径：监看窗口 → 打开波形示波器（Waveform）

- 波形顶部紧贴1023线 → 高光裁切，过曝
- 波形底部紧贴0线 → 暗部裁切，死黑
- 安全画面：波形两端有适当余量，中间调饱满

# 十二、胶片色彩模拟理论

数码仿胶片的核心特征。

## 核心原理

真实胶片的特点：
1. 高光柔化不过刺（高光过渡平滑，不硬截止）
2. 暗部微偏青蓝（胶片特性，数码没有）
3. 灰阶过渡极其顺滑（无明显色阶断层）
4. 肤色柔和不艳丽（饱和有上限，颜色连续）
5. 整体反差偏平但有厚度

## 实操用法

### 用法1：数码素材仿胶片步骤
达芬奇操作路径：Color页面 → Primaries + 曲线联合调整

1. 压低高光硬度：Gain微压 + 曲线右上角做高光滚降（Roll-off）
2. 暗部微加青蓝：Lift色轮往青色方向拖
3. 降低整体饱和：饱和度滑块适当下压
4. 柔化Gamma中间调：曲线中间调区域适当上抬（不要S型高反差）
5. 减少锐化：锐化工具降低或关闭

### 用法2：避免数码感
- 不要高对比（不要把暗部压死，不要把高光拉爆）
- 不要饱和过高（参考真实胶片冲印的饱和度）
- 不要锐化过度（保留灰阶过渡的连续感）

# 十三、色彩层级分离理论

高级调色的核心技术。

## 核心原理

把画面拆成五个独立层级，各调各的互不干扰：

1. 高光层（Highlight）：天空、云层、强光区域
2. 中间调层（Midtone）：主体、肤色、核心内容
3. 暗部层（Shadow）：地面、阴影区域
4. 肤色层（Skin）：人物脸部等肤色区域
5. 环境层（Environment）：背景、道具等非主体

## 实操用法

### 用法：达芬奇窗口+限定器分区域调整
达芬奇操作路径：Color页面 → 窗口（Power Window）工具

操作步骤：
1. 创建圆形/四边形/自定义窗口 → 框住目标区域
2. 打开HSL限定器 → 限定肤色范围（仅调肤色）
3. 单独调整这个窗口内的色轮/曲线/饱和度
4. 叠加第二个节点 → 用窗口+限定器处理另一区域

示例：人像调色
- 节点1（全局）：基础曝光+反差
- 节点2（肤色窗口）：只提亮肤色、略加暖调
- 节点3（背景窗口）：背景降饱和、偏冷青
- 节点4（高光窗口）：天空压饱和、保细节

# 十四、抠像色彩溢出理论

绿幕/蓝幕调色的必备知识。

## 核心原理

绿幕和蓝幕被选用为抠像背景的原因：
1. 人体肤色几乎不含纯绿和纯蓝（和人体颜色色相距离最远）
2. 因此抠像时色彩分离度最高，边缘最干净
3. 代价：抠像后边缘容易残留绿边或蓝边（色彩溢出）

## 实操用法

### 用法1：消除绿幕溢出
达芬奇操作路径：Color页面 → 抠像工具 → 溢出抑制（Spill Suppression）

- 绿幕边缘泛绿 → 溢出抑制工具消绿边
- 往左拖=抑制绿色溢出

### 用法2：选色调色时避开肤色色相区间
达芬奇操作路径：Color页面 → HSL限定器 → 调整色相区间范围

- 做风格化调色时，不小心把肤色色相改了 → 人物脸色变得奇怪
- 用HSL限定器把肤色区间排除在调整范围外
- 永远先确认调色范围不会影响肤色

# 附：达芬奇标准调色工作流（预告）

基于以上理论，推荐的标准调色顺序：

第一步：素材分析
→ 波形示波器观察原始状态
→ 判断是否为Log素材
→ 确认输入色彩空间设置

第二步：黑白场定标
→ Lift/Gain确认暗部不裁切、高光不爆
→ 示波器确认波形两端安全

第三步：曝光还原（Log素材）
→ 套入还原LUT
→ 用Gamma调整中间调

第四步：白平衡校准
→ RGB Parade检查偏色方向
→ 单通道曲线矫正

第五步：反差精调
→ Gamma调中间调反差
→ 曲线做高光滚降
→ 暗部适当填充

第六步：冷暖分离（电影感）
→ HDR色轮：暗部加青、高光加暖
→ 不要全图一个色调

第七步：饱和度控制
→ 矢量镜检查肤色饱和
→ 高光限定器压溢出
→ 暗部饱和不动

第八步：二级分区调整
→ Power Window+HSL限定器
→ 肤色/背景/高光分区精调

第九步：仿胶片（可选）
→ 压高光硬度
→ 暗部微加青
→ 降低饱和、柔化反差

第十步：输出设置
→ Project Settings确认输出色彩空间
→ Deliver页面选Rec.709（网络）/ DCI-P3（院线）
