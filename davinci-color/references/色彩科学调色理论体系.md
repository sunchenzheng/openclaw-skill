# 第一部分：色彩的本质

## 1.1 人眼如何感知颜色

颜色是光与物体、人眼、大脑共同作用的结果。

阳光（白光）照射到物体上，物体会吸收一部分波长，反射剩余部分。被反射的波长进入人眼，人眼三种锥体细胞（L型感红、M型感绿、S型感蓝）分别对不同波长产生反应，最终大脑将这三路信号解读为颜色。

这就是三原色（RGB）体系的基础——所有颜色都可以用红、绿、蓝按不同比例混合得到。

## 1.2 颜色的三个基本属性

任何颜色都有三个不可分割的属性：

**色相（Hue）**
颜色的"长相"，即红、橙、黄、绿、蓝、紫等区分。"这是蓝色还是绿色"问的就是色相。

**明度（Value / Luminance）**
颜色的明暗程度。从黑到白，中间是灰。明度越高越亮，越低越暗。

**饱和度（Saturation）**
颜色的鲜艳程度。饱和度100%是纯色，饱和度0%是灰色（无色彩），同一色相降低饱和度就变成灰调。

## 1.3 加色法与减色法

**加色法**——光的混合（用于屏幕显示）
- 红光 + 绿光 = 黄光
- 绿光 + 蓝光 = 青光
- 红光 + 蓝光 = 品光
- 三种光全加 = 白光

电视、手机屏幕用加色法：每个像素有红、绿、蓝三个子像素，加法叠加出颜色。

**减色法**——颜料/印刷的混合
- 颜料吸收光线而非发出光线
- 青色 + 品红 + 黄色 = 黑色（理论）
- 实际印刷加上黑色（K）来修正

# 第二部分：数字色彩空间

## 2.1 什么是色彩空间

色彩空间（Color Space）定义了在某个系统内"红、绿、蓝"各自能表示多广的范围。

同一组RGB数值，在不同色彩空间里的实际视觉效果完全不同。例如sRGB和Adobe RGB的同一个数字"红"不是同一种红。

## 2.2 常见色彩空间

| 色彩空间 | 应用场景 | 色域范围 |
|----------|---------|---------|
| sRGB | 普通显示器、网页 | 最小 |
| Rec.709 | 高清电视 | 与sRGB相近 |
| DCI-P3 | 电影放映 | 较sRGB大25% |
| Rec.2020 | 4K/8K超高清电视 | 更大 |
| Adobe RGB | 专业摄影 | 绿色区域大于sRGB |
| ACES | 电影工业标准 | 最大 |

## 2.3 什么是色域

色域（Gamut）指某个设备或色彩空间能表示的颜色范围。色域越大，能表示的颜色越多。

色域范围不同，会导致一个问题：在一个色彩空间里能表示的颜色，换到另一个色彩空间可能根本没有对应值（称为"色域外/Out of Gamut"），此时必须做压缩映射，会损失颜色精度。

## 2.4 DaVinci Resolve 中的色彩管理设置

DaVinci使用专属的DaVinci YRGB Color Managed色彩管理体系，三个关键设置：

**Input Color Space**（输入色彩空间）
- 设置为拍摄使用的摄影机对应的色彩空间
- 例如Sony S-Log2、S-Log3、Canon C-Log、ARRI LogC等各自对应不同的Input Color Space

**Timeline Color Space**（时间线色彩空间）
- 调色工作在这个色彩空间内进行
- 常用Rec.709 Gamma 2.4（标准电视）或DaVinci Wide Gamut

**Output Color Space**（输出色彩空间）
- 最终交付的目标色彩空间
- 根据发布平台选择（电视/网络/电影）

这三个设置必须与摄影机的记录格式匹配，匹配错误会导致颜色从源头就不对，后续调色是在"修复错误"而非"创造效果"。

# 第三部分：示波器理论（调色的眼睛）

## 3.1 为什么需要示波器

肉眼对颜色的判断极不可靠。同一个画面，在不同时间、不同环境、不同显示器上看，感受完全不同。示波器（Scopes）用数据说话，让调色决策有客观依据。

## 3.2 波形示波器（Waveform Monitor）

波形示波器是最核心的亮度分析工具。

**刻度标准**
- 0 IRE（DaVinci默认）= 绝对黑（画面的最暗处）
- 1023 DV（Digital Value）= 绝对白（画面的最亮处）
- 正常曝光的安全范围：0~900之间，最亮不超过1023

**怎么看波形**
波形图横轴对应画面从左到右，纵轴对应亮度从下到上。

具体看本案例（稻田场景）：
- 波形底部15~20 IRE（无纯黑，Log素材特征）→ 泥土草丛灰蒙蒙
- 波形中部30~70 IRE（主体集中区）→ 农民、耕耘机所在
- 波形顶部85~90 IRE（接近但未过曝）→ 天空亮度

波形上每一个"山峰"对应画面中相应亮度的区域。山峰越高，该亮度级别的像素越多。

**过曝（Clipping）的判断**
波形数据紧贴顶部1023线无法再往上走，说明高光被裁切，细节丢失（天空变死白）。波形紧贴底部0线，说明暗部被压死，层次丢失（泥土变死黑）。

## 3.3 分量示波器（RGB Parade）

RGB Parade把红、绿、蓝三个通道的波形分开显示，从左到右分别是R、G、B三色的亮度分布。

**怎么看分量Parade**
- 三条波形是否在同一水平线上 → 判断白平衡是否准确
- 如果红色波形整体偏高 → 画面偏红/暖调
- 如果蓝色波形整体偏低 → 画面偏黄/缺少蓝色
- 单独观察某一通道的动态范围 → 判断哪个通道需要优先处理

## 3.4 直方图（Histogram）

直方图横轴是亮度（从黑到白），纵轴是像素数量。它回答："画面中最多的像素集中在哪个亮度区间？"

**本案例Log素材的直方图特征**
- 左侧有大峰（泥土、草丛、阴影）
- 右侧有小峰（天空）
- 中间有凹陷（中间调像素相对少）
- 两端无延伸（没有纯黑纯白）

这说明动态范围两端都还没被利用，素材信息集中在中间调——这是LOG格式的典型特征。

## 3.5 矢量示波器（Vector Scope）

矢量示波器把画面中所有像素的颜色（色相和饱和度）显示在一个圆形图上。圆心是灰色（饱和度0），圆的边缘是纯色（饱和度100）。

**怎么看矢量示波器**
- 色相位置：像素聚集在圆上哪个方向，代表画面主色调
- 饱和度：像素离圆心越远，饱和度越高
- 肤色线：图中有一个小方块标注为"肤色"位置，所有人种肤色大致沿这条线分布，调色师通过矢量示波器确认肤色是否准确

# 第四部分：LOG素材与动态范围

## 4.1 什么是LOG

LOG（Logarithmic，对数）是一种摄影机记录格式的压缩方式。

**线性记录 vs 对数记录**

人眼对光线的感知是对数型的——从蜡烛到阳光，人眼感受到的"明暗变化"不是数学线性的。摄影机传感器记录光线是线性的（光子数量直接转为电信号），但这种线性数据对后期处理不友好（暗部数据太少，亮部数据太密）。

LOG格式把传感器接收的线性信号转换为对数曲线记录，压缩高光、拉升暗部，让10~12档动态范围被更均匀地分配存储。就像把一本书从"字号从小到大依次排列"改成了"字号均匀排列"，信息密度更合理。

**LOG素材的视觉特征**
- 画面灰蒙蒙、对比度低
- 饱和度偏低，颜色发淡
- 亮部不亮，暗部不暗（两端被压缩）
- 好像罩了一层灰雾

本案例帧55的画面就是典型Log素材状态——"七十六个朋友就发了一个片段说在灵感库中看到了这个片子，觉得这种阴天风格很喜欢相反色，但是他弄得像个鬼片，哪里都不对劲啊"。

## 4.2 什么是动态范围

动态范围（Dynamic Range）指摄影机能记录的"最亮"与"最暗"之间的比例，单位是"档（stop）"。

- 普通数码相机：约8~10档
- 专业电影摄影机（ARRI Alexa、RED、SONY Venice）：约14~17档
- 人眼：约20档以上

动态范围越大，能同时记录的亮部细节和暗部细节就越多。高光不爆，暗部不死灰。

## 4.3 为什么LOG素材需要"还原"

LOG格式记录时压缩了动态范围，在显示器上直接观看会显得灰暗扁平。调色师第一步要把LOG素材"还原"（还原到正常对比度），这个过程叫**一级校色（Primary Correction）**，也叫**灰片还原**。

还原不是简单提亮，而是"把被压缩的信息重新展开"——让暗部沉下去（但不死黑），让亮部提起来（但不过曝），让中间调保持自然。

# 第五部分：一级校色工具理论

## 5.1 什么是"一级校色"

一级校色（Primary Correction）是对整个画面做整体亮度、对比度、白平衡调整，目的是建立一个准确的、正常的视觉起点。它回答的问题是："这个画面看起来对不对？"

与"二级调色（Secondary Correction）"不同——二级调色是针对画面中的特定对象（肤色、天空、背景）或特定效果（风格化、情绪化）进行有针对性的调整。

## 5.2 调色的一般原则

原则一：先调反差（对比度），后调色彩
对比度调整会明显影响饱和度的视觉感受。先把亮度框架搭好，再做色彩处理。

原则二：先还原，后风格
先把LOG素材还原为正常画面，再进行风格化调色。本末倒置会导致偏色难以修正。

原则三：用示波器指导，用眼睛最终判断
示波器是工具，不是最终标准。技术正确不一定好看，要结合视觉感受。

## 5.3 色轮工具：Lift、Gamma、Gain

DaVinci Resolve的色轮是调色最核心的工具，分为四个轮：

**Lift（阴影/黑电平）**
- 影响画面中最暗的部分（0~30%亮度区域）
- 数学原理：乘法运算，乘以大于1的系数
- 实际操作：向上拖=提亮阴影（去死灰），向下拖=压暗阴影（加厚重感）
- 配合色彩：向左拖=加青/蓝（冷调），向右拖=加黄/红（暖调）

**Gamma（中间调/灰度）**
- 影响画面中间亮度的部分（30%~70%亮度区域）
- 数学原理：对数运算
- 实际操作：向右拖=整体提亮（但暗部高光一起动），向左拖=整体压暗
- 特点：对暗部和亮部同时有影响，但以中间调为主；是调曝光最常用的工具

**Gain（高光/白电平）**
- 影响画面中最亮的部分（70%~100%亮度区域）
- 数学原理：乘法运算，乘以小于1的系数（相当于除法）
- 实际操作：向上拖=压暗高光（防过曝），向下拖=提亮高光
- 配合色彩：向左拖=减高光中的暖色，向右拖=加高光中的暖色

**Offset（偏移）**
- 影响画面整体（所有亮度区域均匀变化）
- 数学原理：加法运算，在直方图上表现为整体平移
- 实际应用：主要用于白平衡的整体偏移，较少单独使用

**HDR色轮（Extended）**
DaVinci的HDR色轮把亮度区间分得更细：Dark（最暗）、Shadow（暗部）、Midtone（中间调）、Highlight（高光）、Gain（最亮）。比传统色轮更精准，适合HDR素材。

## 5.4 色轮操作的物理意义

理解"乘法"和"对数"背后的物理意义，可以从根本上明白色轮在做什么：

**乘法（Lift和Gain）**
Lift乘大于1 = 把暗部像素值乘以大于1的系数，暗部数值翻倍，变化剧烈
Gain乘小于1 = 把亮部像素值乘以小于1的系数，亮部被压缩，变化剧烈
乘法在坐标轴上是非线性的——越靠近0的数，乘以大系数后变化越小；越靠近1的数，乘以小系数后变化越小。这就是为什么Lift主要影响暗部，Gain主要影响高光。

**对数（Gamma）**
人眼对暗部变化的感知比亮部更敏感。Gamma调整的视觉效果是"均匀地提亮或压暗"，对中间调影响最大，高光和暗端也参与但幅度较小。

## 5.5 曲线工具（Custom Curves）

曲线是色轮的图形化形式，横轴是输入亮度，纵轴是输出亮度。对角线（输入=输出）是未调整状态。

**典型曲线形态**

直线 → 无调整
S型曲线 → 增加对比度（亮部更亮，暗部更暗）
反S型曲线 → 降低对比度（亮部变暗，暗部变亮）
提亮曲线 → 整体向上平移
压暗曲线 → 整体向下平移

**为什么曲线比色轮更精细**

色轮同时影响亮度和色彩（一起拖动），曲线可以单独控制亮度（Y通道）或分别控制RGB通道。分离通道曲线可以在不影响亮度的情况下微调某一颜色的色相。

本案例中讲师用的就是YRGB链接模式，同时调整亮度曲线和色彩曲线。

**曲线的控制点**
在曲线上点击添加控制点，可以把曲线"折弯"，实现局部区域的独立调整。讲师在曲线中间打点，就是为了单独控制中间调的亮度走向，不影响高光和暗部。

**高光滚降（Highlight Roll-off）**
曲线右上角向下压（讲师的操作），是"高光滚降"——让过曝边缘的数据"滚"下来而不是硬切。硬切会产生明显的分界线，滚降则保留过渡，更自然。讲师说"让高光给它找回来"，就是在做这个工作。

## 5.6 饱和度滑块

饱和度控制画面中所有颜色的鲜艳程度。

- 增加饱和度：让颜色更纯、更浓
- 降低饱和度：让颜色变灰、变淡
- 阴天风格：适度保持低饱和，但不要完全没有颜色

注意：调整饱和度之前应该先完成对比度调整。因为饱和度变化会改变颜色的视觉亮度，如果先调饱和度再调对比度，颜色会被二次改变，导致难以判断效果。

# 第六部分：调色决策指南

## 6.1 拿到一段素材，先做什么

**第一步：打开示波器观察原始状态**
- 看波形：亮部到顶了吗？暗部到底了吗？两端还有没有空间？
- 看分量Parade：三个通道平衡吗？偏色方向是什么？
- 看直方图：像素集中在哪个区域？动态范围两端有没有利用？

**第二步：判断是LOG素材还是正常记录**

LOG素材特征：波形两端未达到0和1023，中间调饱满，直方图双峰分布。
正常素材特征：波形两端接近或达到边界，有明显黑白对比。

**第三步：决定工作方向**
- LOG素材：先做灰片还原（一级校色），再风格化
- 正常素材：直接进行对比度和色彩调整

## 6.2 波形不正常时的处理逻辑

**问题：波形顶部超过1023（高光裁切）**
现象：天空/白色衣服等过曝发白
处理：Gain向下压（降低高光），或者用曲线右上角做高光滚降
目标：让波形顶部低于1023，保留高光细节

**问题：波形紧贴底部0（暗部裁切）**
现象：阴影死黑无层次
处理：Lift向上提（提亮阴影），或者在曲线左下角做阴影滚降
目标：让波形底部高于0，保留暗部层次

**问题：波形整体偏暗（曝光不足）**
现象：波形集中在0~50区间
处理：Gamma整体右移（中间调提亮），或Offset整体上移
注意：检查是光线不足还是LOG素材未还原

**问题：波形整体偏亮（曝光过度）**
现象：波形集中在80~1023区间
处理：Gamma整体左移（中间调压暗），或Gain向下压
注意：如果是高光过曝，处理高光而非中间调

## 6.3 不同光线条件的调色策略

**强光环境（阳光直射）**
特征：反差极大，高光亮得刺眼，暗部死黑
策略：Gain适当压高光，Lift适当提暗部，S曲线增加层次
避免：不要把反差压太平，否则画面发灰

**阴天环境（散射光）**
特征：反差小，高光不刺眼，暗部不死黑，中间调偏灰
策略：这是本案例的核心主题——不要认为阴天就要提高反差，正确的阴天感是主动压缩两端（高光下压+阴影填充），让画面在中间调形成正确的阴天氛围
参考图的特征：天空按掉（高光被压缩）、地面反差弱（阴影被填充）、整体发灰但有层次（不是死灰）

**室内人造光环境**
特征：容易偏色（不同光源色温不同）
策略：先用白平衡工具找到中性色基准，再用色轮微调整体色调

**高饱和环境（颜色浓郁的现场）**
特征：绿叶、红花等高饱和色容易溢出
策略：用Luma vs Saturation曲线降低高饱和区域的饱和度，避免颜色刺眼

## 6.4 判断"调对了"的标志

**示波器标准**
- 波形顶部低于1023（高光安全）
- 波形底部高于0（暗部安全）
- 分量Parade三个通道大致等高（白平衡准确）
- 矢量示波器肤色点落在正确位置（肤色判断）

**眼睛标准**
- 天空有云层纹理，不是死白
- 泥土草丛有质感，不是死灰或死黑
- 肤色健康，有血色，不是苍白或发青
- 整体氛围符合预期（阴天就该有阴天的灰调）

# 第七部分：本案例调色操作对应理论

## 7.1 原始素材状态（本案例）

帧55波形分析：
- 阴影：15~20 IRE，无纯黑（波形底部悬空）
- 中间调：30~70 IRE，主体集中区
- 高光：85~90 IRE，无纯白（波形顶部未到顶）
- 色彩：青灰色调，饱和度极低

这是典型的LOG素材未还原状态：高光动态范围顶端被压缩但没被使用，阴影被压缩，主体集中在中间调。

## 7.2 操作1：高光压缩（曲线右上角下压）

**理论对应**
- 目的：把波形顶部85~90的密集信号（过曝天空）拉回100以下
- 操作工具：自定义曲线 — 高光控制点下压，做高光滚降（Highlight Roll-off）
- 示波器变化：波形顶部从85~90收缩，变得更平缓，云层细节显现

**为什么不用Gain色轮直接压高光？**
Gain是直接压缩，会把整个高光区间一起压，导致亮部整体变暗。曲线操作可以更精细地只处理最亮的那部分（右上角的点），对中间调影响更小。

## 7.3 操作2：阴影填充（曲线左下角上抬）

**理论对应**
- 目的：把波形底部从15~20提升，给阴影增加厚度
- 操作工具：自定义曲线 — 阴影控制点右移+上抬
- 示波器变化：波形底部从15上升到有一定厚度的基底，泥土草丛质感增强

**什么是"正确的阴天"？**
阴天不是没有反差，而是高光被压缩、阴影被填充，整体反差被压缩在中间区间。操作后的波形应该是"两端向中间靠拢，中间撑满"——这正是讲师说的"阴天质感"。

## 7.4 操作3：中间调微调（曲线中间加点）

**理论对应**
- 目的：控制整体曝光感觉，不影响高光和暗部
- 操作工具：曲线中间打点，上抬（画面偏暗时）或下压（画面偏亮时）
- 示波器变化：波形中间区域整体上移或下移，两端位置不变

这是讲师凭视觉判断的操作，不是固定公式。"我觉得这个程度就差不多了"——说明中间调调整是经验判断，不是数学计算。

## 7.5 操作4：适当增加饱和度

**理论对应**
- 阴天环境特征：颜色不会太厌脸（不会高饱和），但也不是没有颜色
- 操作：适当加饱和度，让颜色有"沉稳"的阴天感
- 注意：不要过度，阴天风格不是小清新高饱和

## 7.6 操作5：HDR色轮色调校正

**理论对应**
- 问题：LOG素材整体偏青灰色调（冷调）
- 操作：HDR色轮增益（Gain）向黄色/暖色方向移动
- 目的：中和青灰，给绿色和肤色注入暖调

**为什么用HDR色轮而不是曲线？**
HDR色轮可以分区处理（Dark、Shadow、Midtone、Highlight），比传统色轮更精准。讲师选择用增益（Gain）轮针对高光区域加暖，同时不影响中间调和暗部太多。

## 7.7 核心理论总结

讲师的操作本质上是对"动态范围分配"的重构：

```
原始状态（LOG）：
高光: ████████░░░░░░░░░░░░░░░░░░░ 85-90 IRE（有压缩未用）
中间: █████████████████████████░ 30-70 IRE（集中）
阴影: ████░░░░░░░░░░░░░░░░░░░░░░ 15-20 IRE（底部悬空）
        ↓
调色后（阴天质感）：
高光: ████████░░░░░░░░░░░░░░░░░░ 70-85 IRE（滚降保留细节）
中间: ████████████████████████░░░ 35-65 IRE（主体通透）
阴影: ████████████░░░░░░░░░░░░░░ 25-35 IRE（有厚度有质感）
```

不是"提高反差"，也不是"降低反差"，而是"把两端信息正确填入中间区间"——这就是阴天调色的核心。

# 第八部分：实践检查清单

## 拿到新素材时的检查流程

□ 1. 打开波形示波器，观察整体亮度分布
□ 2. 打开分量Parade，观察是否有偏色
□ 3. 打开直方图，观察像素分布范围
□ 4. 判断是否为LOG素材（两端悬空）
□ 5. 检查是否有高光裁切（>1023）或暗部裁切（<0）
□ 6. 先处理高光（如果过曝）还是先处理阴影（如果死黑）？
□ 7. 用曲线或色轮做初步动态范围展开
□ 8. 用示波器确认调整后波形两端安全
□ 9. 检查白平衡（分量Parade是否平衡）
□ 10. 增加饱和度到合适程度
□ 11. 打开Split Screen做前后对比
□ 12. 结合参考图或视觉感受做最终微调
